# ProofCast 3-Minute Demo Script

## 0:00 - Hook

"Blockchains are permanent, but their history is hard to understand. ProofCast turns any Sui address into an AI-powered, verifiable memory timeline."

## 0:20 - Problem

"Wallets, DAOs, treasuries, and NFT collectors generate constant activity. Months later, it is difficult to explain what happened, prove what changed, or share the story with non-technical people."

## 0:45 - Solution

"ProofCast is a time machine for Sui. It uses Tatum as the real-time blockchain intelligence layer, Walrus as the permanent memory layer, DeepSeek for explanations, and Sui anchors for public proof."

## 1:05 - Live Demo

"I paste a Sui address and click Generate ProofCast. The app fetches balances, transactions, NFTs, events, and latest checkpoint through Tatum Sui RPC. No data is mocked."

"Now the snapshot engine builds canonical JSON, hashes it, asks DeepSeek for an activity summary and risk score, then stores the complete snapshot and AI report on Walrus."

## 1:45 - Walrus Proof

"Here are the Walrus blob IDs and proof links. The full historical state lives on Walrus, not in local UI state. The database is only an index."

## 2:05 - Tatum Proof

"The dashboard visibly shows Tatum-powered chain reads: transaction history, NFT objects, contract events, checkpoints, and treasury activity."

## 2:25 - Replay + Share

"Replay Mode reconstructs the wallet over time from Walrus-backed snapshots. The public ProofCast page is shareable and verifiable without login."

## 2:45 - Closing Pitch

"ProofCast makes Sui history understandable, permanent, and provable. Walrus stores the memory. Tatum powers the intelligence. Together they create a new category: verifiable onchain memory."
